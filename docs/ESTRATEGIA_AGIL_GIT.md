# Estrategia ágil y control de versiones

## Metodología de trabajo

Para el desarrollo del proyecto Reserva de Horas Médicas se propone utilizar Scrum y Kanban como enfoques complementarios.


## Estrategia de control de versiones

Se utilizará Git como sistema de control de versiones y GitHub como plataforma de colaboración.

### Gestión de ramas

- main: contiene la versión estable del proyecto.
- feature/: permite desarrollar nuevas funcionalidades.
- fix/: permite corregir errores.
- docs/: permite incorporar documentación.

### Registro de cambios

Cada modificación deberá registrarse mediante commits con mensajes descriptivos utilizando convenciones como feat, fix, docs y test.

### Pull Request

Los cambios desarrollados en ramas secundarias deberán publicarse en GitHub mediante Pull Requests.


### Revisión

Antes de integrar los cambios, se realizará una revisión del código y se verificarán las funcionalidades afectadas.

Una vez aprobados los cambios, se realizará el Merge hacia main.

## Beneficios esperados

- Trazabilidad de los cambios.
- Reducción de conflictos entre desarrolladores.
- Mayor control sobre las versiones.
- Revisión del código antes de integrarlo.
- Conservación de un historial de desarrollo verificable.
