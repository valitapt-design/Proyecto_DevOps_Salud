# Fase 05 – RELEASE

## 1. Descripción

La fase RELEASE corresponde a la preparación de la primera versión estable del proyecto DevOps – Reserva de Horas Médicas.

## 2. Versión

- Aplicación: Reserva de Horas Médicas
- Versión: 1.0.0
- Servidor web: Nginx 1.31.8
- Contenedorización: Docker
- Orquestación: Docker Compose

## 3. Validaciones previas

- Construcción de imagen Docker.
- Inicio correcto del contenedor.
- Verificación HTTP 200 OK.
- Validación de archivos HTML y CSS.
- Pruebas funcionales del formulario.
- Reinicio y disponibilidad del servicio.

## 4. Resultado esperado

Disponer de una versión estable, documentada y respaldada en GitHub, preparada para su liberación.
